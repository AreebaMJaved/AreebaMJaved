## About

I'm a Software Engineering graduate/developer focused on full-stack web development, with an emphasis on the MERN stack — React and Next.js on the frontend, Node.js and Express on the backend, and MongoDB or SQL databases depending on the use case. My background in Software Engineering gives me a working foundation in data structures, system design, and the SDLC, which I try to carry into how I structure and test the applications I build. Alongside frontend and backend work, I'm spending time on test automation, cloud deployment, and integrating AI/LLM APIs into web applications.
